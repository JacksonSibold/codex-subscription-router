# Relay 1.0.0

Relay 1.0 brings ChatGPT/Codex, Claude, Kimi Code, OpenCode Go, and local OpenAI-compatible models into one private Codex model catalog. Each model keeps its own provider lane, credential, protocol adapter, tools, reasoning levels, and usage record.

## Downloads

- **Windows 10/11:** `relay-1.0.0-windows.zip`
- **Linux:** `relay-1.0.0-linux.tar.gz`
- **macOS 13+:** `relay-1.0.0-macos.tar.gz`
- **Verification:** `SHA256SUMS.txt`

These are unsigned portable archives for users who already have Python 3.11 or newer and Codex installed. They are not signed or notarized `.exe`, `.msi`, `.pkg`, `.dmg`, or package-manager installers.

## Highlights

- **Claude OAuth without OpenCode.** Connect an eligible Claude Pro, Max, Team, or Enterprise account through Relay-owned PKCE OAuth. Existing OpenCode Anthropic tokens remain an optional legacy fallback.
- **Any provider in the same picker.** OpenAI, Claude, Kimi Code, OpenCode Go, and local models can share one Codex catalog through stable Relay route IDs.
- **Cross-provider child agents.** Any visible, enabled, subagent-eligible route can be used as a child target from any provider lane. OpenAI, OpenCode, Claude, Kimi, and local child routing are covered by regression tests.
- **Provider-populated add-model menu.** The grouped dropdown includes OpenAI, Claude, Kimi, and OpenCode catalogs, configured routes, and cached local provider models.
- **Custom and edited IDs are preserved.** An upstream model ID no longer has to exist in a local provider cache before Relay can generate its Codex catalog entry.
- **Local models.** Discover Ollama, LM Studio, or another loopback OpenAI-compatible endpoint, choose Chat Completions or Responses, edit the connection later, and use the model for normal or delegated work.
- **All connected accounts in usage.** Codex, Claude, Kimi, OpenCode, and each local endpoint appear even before their first request. Historical account labels remain in the local ledger after a route changes.
- **Live subscription allowances.** Read provider-reported Codex, Claude, and Kimi used percentages and reset times, including an unexpired legacy OpenCode Claude token. OpenCode and local lanes remain token-ledger-only because no supported subscription-percentage API is exposed through Relay.
- **Blue Relay interface.** Overview, Connections, Model picker, Usage, Capabilities, and Diagnostics use the same blue production theme and responsive layout.
- **Non-disruptive apply.** Save or apply credential-free preferences, regenerate the catalog, update the selected Codex default, and request a router reload without restarting Codex.

## Upgrade from 0.3.0

1. Download the archive for your operating system.
2. Quit only the existing Relay manager and router processes you intend to replace. Codex can remain running.
3. Install with the same Codex home and preserve the generated backups:

   Windows: `python scripts\install.py --configure-codex`

   macOS or Linux: `python3 scripts/install.py --configure-codex`

4. Start `Start Router` and then `Start Relay` for your platform.
5. Open Connections and reconnect a provider only if its status reports that reconnection is required.

Settings and usage records are separate from provider credentials. The installer preserves existing Relay preferences and makes timestamped backups before replacing files or changing selected Codex defaults.

## Verification

Relay 1.0.0 is gated by:

- Python regression tests, source/credential validation, production UI compilation, and rendered UI checks.
- Python 3.11 compatibility validation.
- Native Windows, Linux, and macOS CI.
- An isolated extraction, installer rehearsal, and launch test for each packaged archive, including manager API, static UI, add-model catalog, usage inventory, router health, and Codex configuration preservation.
- Tag/version consistency and archive allowlists.
- Post-publication download and SHA-256 verification of all three assets.

## Known limits

- Provider OAuth flows, model IDs, quotas, allowance endpoints, and tool compatibility can change without provider notice.
- Claude OAuth and subscription eligibility remain controlled by Anthropic.
- Hosted web search and large connected-app namespaces remain OpenAI-only.
- Local model quality, context size, image support, and tool calling depend on the local server and model.
- Relay archives are portable and unsigned; native signed installers, automatic transactional rollback, and a dedicated uninstaller are post-1.0 work.

Relay is an independent project and is not affiliated with or endorsed by OpenAI, Anthropic, Kimi, or OpenCode.
