# Relay 1.0.2

Relay 1.0.2 is a model-picker hotfix for the 1.0 line. It keeps the same five provider lanes, live model catalogs, Codex-on-this-PC linking, cross-provider subagents, local-model support, usage dashboards, and blue interface.

## Downloads

- **Windows 10/11:** `relay-1.0.2-windows.zip`
- **Linux:** `relay-1.0.2-linux.tar.gz`
- **macOS 13+:** `relay-1.0.2-macos.tar.gz`
- **Verification:** `SHA256SUMS.txt`

These remain unsigned portable archives for users who already have Python 3.11 or newer and Codex installed. They are not signed or notarized `.exe`, `.msi`, `.pkg`, `.dmg`, or package-manager installers.

## Fixes

- Hiding the current default model no longer leaves Relay pointing at an invisible route. The next visible model on an enabled provider becomes the default automatically.
- Disabling the default route's provider or removing the default route now performs the same safe replacement.
- If no visible model remains on an enabled provider, Relay keeps the previous valid state and explains what must stay enabled.
- Apply now succeeds after these edits instead of repeatedly returning `runtime.default_model: default model must be visible and use an enabled provider`.
- Added focused regression coverage that runs before every production interface build.

## Upgrade

1. Download the archive for your operating system.
2. Stop only the Relay manager and router processes you intend to replace. Codex can stay open.
3. Run the installer with `--configure-codex` using the same Codex home. Timestamped configuration and source backups are retained.
4. Start the updated router, then the Relay manager.
5. Open a new Codex conversation to load the refreshed picker.

There are no settings-schema or credential migrations. Existing Relay preferences, connected accounts, and usage records are preserved.

## Verification

The release workflow requires the default-model regression test, Python tests, source and credential validation, a production build, rendered UI checks, native Windows/Linux/macOS archive launch and installer tests, tag/version consistency, and post-publication SHA-256 verification.

## Known limits

- Provider OAuth flows, model IDs, quotas, allowance endpoints, and tool compatibility can change without provider notice.
- Claude OAuth and subscription eligibility remain controlled by Anthropic.
- Hosted web search and large connected-app namespaces remain OpenAI-only.
- Local model quality, context size, image support, and tool calling depend on the local server and model.
- Relay archives are portable and unsigned; native signed installers, automatic transactional rollback, and a dedicated uninstaller are post-1.0 work.
