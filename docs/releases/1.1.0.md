# Relay 1.1.0

Relay now opens as a native desktop companion instead of requiring a terminal command or a browser tab.

## Highlights

- Native Relay window for Windows, Linux, and macOS, packaged with its Python backend.
- On first launch, Relay registers a per-user startup entry that waits quietly for Codex and opens beside it when Codex starts.
- Closing Relay hides it; the tray/menu-bar icon can show it again or quit.
- The desktop window is positioned beside the Codex window on Windows when both are visible.
- Provider catalogs refresh at startup and every 15 minutes, persist safely, and mark newly discovered models in **Add model**.
- Codex-link diagnostics now explain exactly why a link is unavailable and how to repair it.
- Model failures now identify authentication, quota, missing model IDs, context limits, tool incompatibility, provider outages, and local-endpoint failures in plain language.
- Route health checks flag missing credentials and configured upstream IDs missing from the latest catalog.
- Development launchers use isolated repository state and can no longer be mistaken for the live Codex installation.

The desktop executables are unsigned. Windows SmartScreen, macOS Gatekeeper, or Linux desktop security prompts may require you to review the warning and explicitly allow the app. Verify the published checksum before opening any downloaded build.

## Upgrade notes

Relay never restarts Codex during upgrade. Existing preferences, credentials, usage history, and unrelated Codex configuration are preserved. If an older browser manager or router is still running, Relay attaches to the healthy local services or starts isolated desktop services without terminating an active Codex conversation.
